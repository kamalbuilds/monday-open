# MONDAY OPEN — UI concept

A responsive React + Vite implementation of the MONDAY OPEN mockup.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL Vite prints (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Included interactions
- Buy/Sell tab switching
- Editable limit price and share quantity
- +/- controls and estimated order-value calculation
- Demo-only order submission feedback
- Expand/collapse educational rows on mobile

## Important
This is a front-end UI prototype only. The market chart, order counts, prices, recent orders, countdown and program address are illustrative demo content. No wallet is connected, and no transaction is submitted to Solana. Replace the demo handlers and sample data with your existing program/API integration before using it in production.
